# 前后端联调验证记录 v0.4

日期：2026-09-05  
对象：`开发/frontend` v0.4.0 与 `开发/backend` v0.4  
结论：当前后端核心接口已完成浏览器接线和本地闭环验证；这不是生产上线或完整 V1 验收。

## 实现范围

- 默认前端模式改为真实 API，启动时检查会话；未登录进入真实登录表单。
- 使用 HttpOnly 会话 Cookie、预认证／会话 CSRF，并在需要的操作上发送幂等键。
- 对接工作空间、服务状态、会话、消息列表、SSE 流式回复、运行取消、安全删除和任务查询。
- 对接 OpenAI 兼容供应商连接、密钥提交、部署价格、连接测试 Job。
- 对接助手元数据、草稿、启用、撤销及默认版本。
- 对接预算策略、调用 Token、工作空间预算账户消费与预留。
- 后端未实现的导出、末轮重试、迁移和对账修正不在真实模式中伪造成功。

## 验证结果

| 命令 | 结果 | 覆盖 |
| --- | --- | --- |
| `pnpm build` | 通过 | Vue/TypeScript 类型检查和生产构建 |
| `pnpm test` | 16/16 通过 | v0.3 状态边界回归 |
| `pnpm test:e2e` | 22/22 通过 | 显式 `VITE_DEMO_MODE=true` 的冻结版浏览器回归 |
| `pnpm test:e2e:live` | 1/1 通过 | 真实 Uvicorn、Vite、本地 OpenAI 兼容 HTTP 服务和一次性 Worker |

真实浏览器用例按以下顺序执行：管理员登录 → 保存预算策略 → 提交连接和真实测试 → Worker 完成模型清单及最小调用 → 创建助手草稿 → 启用并设为默认 → 新建会话 → 接收 SSE 回复“前后端联调成功” → 刷新页面确认消息仍由后端返回。

测试供应商只监听 `127.0.0.1`，测试数据库位于系统临时目录，不调用外部模型，不使用生产密钥或生产数据。普通 22 项浏览器回归显式使用演示模式，因此不会因后端状态变化而污染 v0.3 冻结基线。

- 获准生产供应商、真实价格、账单对账与数据处理边界。

因此本记录支持“核心前后端已相连并可本地运行”，不支持“系统已经达到生产交付或上线标准”。
