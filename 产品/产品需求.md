## 1. 产品目标与用户

让管理员使用自己的模型 API Key 建立聊天能力，保存可管理的对话，再将经审核的业务资料用于客服回答，并由人工处理复杂或无法确认的问题。训练属于后期优化手段，其投入取决于实测收益。

| 角色 | 主要任务 | 访问边界 |
| --- | --- | --- |
| 管理员／发起人 | 管理模型、支出、配置、导出与停用 | 凭据管理与其他权限分别授权 |
| 内部使用者 | 多轮聊天、历史、停止、重试和反馈 | 只访问获准会话与助手 |
| 匿名访客 | 咨询公开业务资料 | 不查询个人订单、工单或账户记录 |
| 已验证客户 | 在可信业务身份下使用已启用个人能力 | 同一业务主体与资源权限均需有效 |
| 人工客服 | 接管、答复、交接与结案 | 只读获准材料，无被拒 AI 候选的默认审查权 |
| 知识运营／质检／审核人员 | 资料发布、纠错、评测和专项审查 | 分别授予内容管理与专用审核权限 |

## 2. 分期与优先级

| 阶段 | 交付目标 | 边界 |
| --- | --- | --- |
| V0 | 验证一个模型连接和最小多轮原型 | 仅测试数据，有上限的验证支出 |
| V1 | 内部聊天与数据管理闭环 | G1 后正式开发；Must 必须验收，Should／Could 可调整 |
| V2 | 知识库、审核、访客与人工客服试点 | 公开前通过 G3；不默认开启个人查询 |
| V3 | 已选业务接口与受控工具 | 每个接口独立验证身份、权限、费用与写入结果 |
| V4 | 合格训练资产与模型优化实验 | 来源、用途、资格及评测证据具备后再排期 |

Must 为该阶段必须交付；Should 为应做但可明确延期；Could 为可延后。后续规划不列为 V1 缺陷，也不代表已经承诺交付日期。

## 4. 功能要求

### FR-00 最小接口验证

适用：V0 · 优先级：验证项 · 使用者：开发／内部验证者

使用测试数据完成一个服务端模型连接、简单多轮对话、流式展示及错误处理；记录实际模型能力与费用。验证成功不等于具备真实数据保存、删除或公开服务能力。

依据：技术 3.1；PRD 4、9。验收：[AC-00](E:/ai-customer-service-plan/产品/验收标准.md)。

### FR-01 账号、权限与模型连接

适用：V1 · 优先级：Must · 使用者：管理员／内部使用者

用户登录后仅访问自己获准的会话和助手；管理员配置一个供应商连接、测试和轮换 Key。Key 只在服务端使用，界面、导出与日志不泄露；普通聊天用户不取得供应商 Key。

依据：技术 3.2、4.2、13.1；PRD 4.1。验收：[AC-01](E:/ai-customer-service-plan/产品/验收标准.md)。

### FR-02 发送、停止与断流恢复

适用：V1 · 优先级：Must · 使用者：内部使用者

同一会话同时只能有一个生成或审核任务。重复提交不重复创建提问；停止尽力取消。检测断流后终止，刷新读取原任务可见快照；不自动重新付费生成，已完成结果不因结束通知丢失而变失败。

依据：技术 6.2、6.6、7；PRD 6.1。验收：[AC-02](E:/ai-customer-service-plan/产品/验收标准.md)。

### FR-03 多轮上下文与有效内容

适用：V1 · 优先级：Must · 使用者：内部使用者

新建会话不默认读取其他会话；模型仅使用本会话必要历史、有效完整答案和仍允许使用的摘要。已删除、被撤销或未获准内容不能进入后续模型请求；全部上下文计入输入上限。

依据：技术 6.1、6.3、6.7、14.2。验收：[AC-03](E:/ai-customer-service-plan/产品/验收标准.md)。

### FR-04 末轮重新生成

适用：V1 · 优先级：Must · 使用者：内部使用者

只允许重试当前最后一轮，且当前没有活动生成。成功的新完整答案获准后才替换旧有效答案；失败、取消或审核拒绝保留旧有效答案。重试沿用原轮的金额、Token、次数和时限。

依据：技术 6.3、7；PRD 6.1。验收：[AC-04](E:/ai-customer-service-plan/产品/验收标准.md)。

### FR-05 历史记录与数据访问

适用：V1 · 优先级：Must · 使用者：内部使用者

提供分页历史，显示真实发送者、时间、任务状态与获准内容。失败片段明确标为未完成；历史、任务查询和刷新遵守相同权限及可见范围。搜索、重命名和高级筛选可延期。

依据：技术 6.6—6.7、7、8；PRD 4.1、6.1。验收：[AC-05](E:/ai-customer-service-plan/产品/验收标准.md)。

### FR-06 安全删除与备份恢复

适用：V1 · 优先级：Must · 使用者：数据主体／授权管理员

删除先阻断相关读写，独立日志持久确认并完成本地关联后才显示已持久受理。日志未确认显示待确认并保持阻断；在线清理、备份到期及外部处置分别展示。恢复旧备份先重放最新完整删除记录。

依据：技术 6.4、13.2、13.6；PRD 9.3；运营 6—7。验收：[AC-06](E:/ai-customer-service-plan/产品/验收标准.md)。

### FR-07 授权导出与数据迁移

适用：V1 · 优先级：Must · 使用者：授权管理员

首版以授权管理任务完成必要导出与迁移验证，无需自助导出页面。导出只含允许取得的内容，发布和下载复验当前授权、来源和审核状态；保留应有 AI 标识及来源关系。

依据：技术 3.2、6.4、7、8.4；PRD 4.1。验收：[AC-07](E:/ai-customer-service-plan/产品/验收标准.md)。

### FR-08 费用预算与对账

适用：V1 · 优先级：Must · 使用者：管理员／财务

按用户、工作空间、会话和一次提问限制支出；生成、摘要、重试、审核及辅助调用全部归账。派发前预留；费用未知保留占用，迟到用量不重复结算。金额、币种或费用上界未配置时禁用相应收费能力。

依据：技术 14.1—14.2；PRD 3、5。验收：[AC-08](E:/ai-customer-service-plan/产品/验收标准.md)。

### FR-09 配置版本与撤销回退

适用：V1 · 优先级：Must 核心；Should 完整界面 · 使用者：管理员

提示词、模型和预算策略有版本；已建会话绑定可追溯版本。撤销阻止新旧会话继续执行和发布；默认回滚不自动迁移旧会话。可先用受控命令维护，完整界面可后移。

依据：技术 5.3、7；PRD 4.1。验收：[AC-09](E:/ai-customer-service-plan/产品/验收标准.md)。

### FR-10 后台任务与文件管理

适用：V1；V2 扩展上传 · 优先级：Must · 使用者：管理员／知识运营

后台任务可查状态、失败原因和处理进度；失联接手不盲目重做未知外部调用。文件先登记意图再写入，校验通过才可下载；临时文件、未完成上传及迟到产物都纳入清理。

依据：技术 5.5、6.5、8.4。验收：[AC-10](E:/ai-customer-service-plan/产品/验收标准.md)。

### FR-11 紧急停用与基础观测

适用：V1 · 优先级：Must · 使用者：管理员／产品／运维

可按批准权限紧急停用 AI；V1 显示暂停，V2 展示实际可用人工入口。记录提交、成功、失败、取消、预算阻断和服务模式事件；事件最小化且可去重，保留费用对账。

依据：技术 5.4、8.3、12.5；PRD 5、8.2。验收：[AC-11](E:/ai-customer-service-plan/产品/验收标准.md)。

### FR-12 评分与纠错

适用：V1 评分；V2 纠错 · 优先级：Should → V2 完整闭环 · 使用者：用户／质检／知识运营

V1 可有帮助／无帮助评分；未做 UI 时使用内部问题台账并注明评分指标不可用。V2 增加原因、独立纠正答案、分派、验证与关闭依据，不能覆盖原回答或自动进入训练集。

依据：技术 3.2、8.1；PRD 4、5；运营 4。验收：[AC-12](E:/ai-customer-service-plan/产品/验收标准.md)。

### FR-13 可选界面增强

适用：V1 可延期 · 优先级：Could · 使用者：内部使用者／管理员

自助导出、全文搜索、批量筛选、重命名、图形用量看板和高级格式均可延期。延期不取消授权导出、分页历史、预算记录和版本撤销；未启用自助能力不开放对应入口。

依据：技术 3.2、7；PRD 4.1。验收：[AC-13](E:/ai-customer-service-plan/产品/验收标准.md)。

### FR-14 知识库与可靠回答

适用：V2 · 优先级：Must · 使用者：知识运营／客户

支持 FAQ、Markdown、文本及可提取文字 PDF；上传后预览、审核、发布，明确来源、权限、版本和有效期。答案引用可访问的有效资料；无资料或冲突先澄清或转人工，过期资料退出检索并失效缓存。

依据：技术 9；PRD 1.1、6.4；运营 2。验收：[AC-14](E:/ai-customer-service-plan/产品/验收标准.md)。

### FR-15 全文审核与统一可见内容

适用：V2 · 优先级：Must · 使用者：客户／内容审核人员

公开答复先全文生成并审核，通过后展示。待审、拒绝、超时或审核额度不足时不展示候选原文，所有历史、快照、复制、导出、摘要和上下文遵守同一规则；专门审查权限与普通客服权限分开。

依据：技术 6.7、13.5、14.2；PRD 6.1、7。验收：[AC-15](E:/ai-customer-service-plan/产品/验收标准.md)。

### FR-16 访客续期与可信业务身份

适用：V2；V3 个人查询前 · 优先级：Must 访客；身份按接入范围 · 使用者：匿名访客／已登录业务客户

访客只能访问公开知识和获准聊天；默认 15 分钟凭证、8 小时绝对期限。按活动与期限续期，过期清空展示缓存且不能凭会话号读历史。业务身份须由可信系统验证；退出后个人历史不能退为匿名可读。

依据：技术 13.4；PRD 6.3。验收：[AC-16](E:/ai-customer-service-plan/产品/验收标准.md)。

### FR-17 人工接管与服务登记

适用：V2 · 优先级：Must · 使用者：客户／人工客服／客服主管

客户可随时请求人工；受理进入队列即停止 AI 新回复。显示真实队列、服务时间和客服身份；无坐席时给可用渠道。留单经用户确认，只表示本系统登记，不伪造外部工单或通知；转回 AI 需授权客服操作。

依据：技术 10.2；PRD 6.2、6.4；运营 3。验收：[AC-17](E:/ai-customer-service-plan/产品/验收标准.md)。

### FR-18 中文网页与可用体验

适用：V1 基础；V2 完整 · 优先级：Must 核心 · 使用者：内部使用者／客户

首期简体中文独立网页；状态提示可理解，窄屏可完成核心操作。V2 覆盖聊天、转人工、续期过期、知识兜底及移动／无障碍五流程；复制内容保留应有 AI 标识。

依据：技术 4、12.5；PRD 6。验收：[AC-18](E:/ai-customer-service-plan/产品/验收标准.md)。

### FR-19 数据用途、权利与公开准入

适用：V1 适用义务；V2 公开准入 · 优先级：Must · 使用者：数据主体／产品／数据负责人

按数据类别明确用途、依据、期限和接收方；提供权利与投诉处理路径，V1 可受控人工办理。训练和长期记忆默认关闭；公开前完成 PRD 的 C01—C07 适用性检查、真实文本与处置流程。

依据：技术 13；PRD 7；运营 6—7。验收：[AC-19](E:/ai-customer-service-plan/产品/验收标准.md)。

### FR-20 质量评测、指标与灰度

适用：V1 基础观测；V2 试点 · 优先级：Must · 使用者：产品／质检／财务

指标按待解决问题统计，区分 AI 独立解决、人工处理、未确认及 72 小时重开。按种子、5%、25%、100% 逐步开放，样本、观察期和质量成本门槛均满足才扩量；重试不重新抽组。

依据：技术 12；PRD 3、5、8；运营 5。验收：[AC-20](E:/ai-customer-service-plan/产品/验收标准.md)。

### FR-21 受控业务工具

适用：V3 · 优先级：后续规划 · 使用者：已验证客户／客服

先接有收益的查询，再逐个开放写入。后端核验身份、参数、权限和业务确认；写入幂等，未知结果先核对。回答失败不冒充执行成功，重新生成不能重放已发生的业务写入。

依据：技术 6.3、10.1、14.2；PRD 4.2。验收：[AC-21](E:/ai-customer-service-plan/产品/验收标准.md)。

### FR-22 训练资产与模型优化

适用：V4 · 优先级：后续规划 · 使用者：数据负责人／质检／开发

先比较提示词、知识检索和工具改进，再判断是否微调。训练样本须具备用途依据、脱敏、人工审核和来源血缘，数据集版本化并隔离评测。训练资格和产物能力单独验证，删除样本不承诺模型立即遗忘。

依据：技术 11—12；PRD 4.2、7。验收：[AC-22](E:/ai-customer-service-plan/产品/验收标准.md)。

## 5. 必须一致的用户流程

| 触发 | 页面与服务行为 | 后续动作 |
| --- | --- | --- |
| 发送问题 | 用户气泡和“正在处理…”；V1 内部可展示获准片段，V2 先完整生成审核 | 提供停止；活动生成／审核期间不提交下一轮 |
| 网络中断或刷新 | 查询原任务，以可见快照替换旧文本；只保留此前获准片段 | 失败时可主动末轮重试；已完成则恢复完成结果 |
| 审核中／被拒／超时 | 审核中显示“正在核对回复内容…”；无获准内容不显示候选原文 | 固定提示及真实人工入口，不能摘录被拒文本解释 |
| 限额达到 | “当前暂时无法继续自动回答。”，停止新的受限调用 | V1 联系管理员；V2 人工或服务登记 |
| 用户请求人工 | 服务端受理即停止 AI 新回复，显示实际队列／服务状态 | 超时可继续等待、取消、确认留单；离开不算解决 |
| 无依据或资料冲突 | 先必要澄清，仍无法核实则说明并提供人工入口 | 同一问题连续两次未解决主动提供人工入口 |
| 访客过期／退出 | 清空旧会话展示缓存，停止内容发布；过期不等于数据已删除 | 新公共会话或可信重新认证，不凭旧会话号恢复权限 |
| 删除提交 | 先阻断；只有独立凭证及本地关联确认后显示已持久受理 | 分别跟踪在线副本、外部处置和备份到期 |
| AI 停用 | V1 暂停；V2 按真实能力切人工、暂停或留单 | 不继续旧任务发布，不清零已经发生的费用 |

访客续期细节沿用原 PRD 6.3：过去 5 分钟有前台活动且剩余 ≤ 3 分钟时串行续期；失败且剩余 < 2 分钟预警；距绝对期限不足 5 分钟提示。后台不无限保活。草稿只在有效会话当前页内存；随机提交标识可用于刷新定位，但不含正文或凭证，也不授予读取权。

会话是否删除、是否人工服务、生成是否完成和内容是否获准是不同状态。删除或失权不能通过重试、人工重开或刷新恢复；“生成完成”也不能代替审核通过。

## 6. 共用预算与体验约束

本表是 v1.3 默认档位的执行摘要；币种、金额及实际供应商仍待决定。参数变更须有版本并重新验证，详规见技术设计 14.2。

| 项目 | V1／V2 规则 |
| --- | --- |
| 单次输入／输出 | 输入总量 ≤ 4,000 Token；输出上限 1,200 Token，适配实际模型参数 |
| 一次用户提问累计 | 全部尝试输入加输出 ≤ 24,000 Token；模型尝试最多 3 次，含摘要、LLM 审核和重试 |
| 辅助调用 | V1 不做在线知识检索；V2 在线向量／独立检索／重排最多 3 次，LLM 重排计入模型次数 |
| 独立审核接口 | 最多 2 次提交，含重试；LLM 审核按模型次数计算；均计入金额和时限 |
| 网络重试 | 同一操作最多 1 次，一次提问合计最多 2 次；未知非幂等请求不盲目重发 |
| 执行时限 | 单次生成／重试最多 120 秒，一次提问累计运行最多 180 秒；重试不重置 |
| 业务工具 | V1／V2 为 0；V3 另档位按原设计最多 4 次模型、3 次工具尝试 |
| 未知费用 | 继续保留可能消费的预留，核对后结算，不因断流／删除清零 |
| 内部响应目标 | support-text-v1：p95 首字 ≤ 5 秒，完整回复 ≤ 30 秒 |
| 公开审核响应目标 | support-text-reviewed-v1：p95 获准首字 ≤ 35 秒，完整回复 ≤ 40 秒；等待提示不算首字 |

性能的负载、分母与成功率按[验收标准](E:/ai-customer-service-plan/产品/验收标准.md)执行；上述是未实测目标。原始对话、知识、训练集用途分开管理；候选和历史的保留期限按产品决策 O-08／O-09 落实。

## 7. 首期不包含与前置条件

V1 不包括外部访客、知识库检索、个人业务查询、自动训练、长期记忆、语音、复杂多代理或多商家 SaaS 计费。OCR、跨域挂件、多语言、每人自带 Key、增量审核和自动退款不在当前首期承诺中；需要时新增范围、决策和验收条目。

业务场景、预算、实际模型、数据用途、资料来源和人员安排按[产品决策 O-01—O-12](E:/ai-customer-service-plan/产品/产品决策.md)跟踪。V0 可以在测试数据与授权预算内先验证，不能用原型成功越过真实数据或公开服务准入。
